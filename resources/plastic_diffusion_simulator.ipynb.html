## Plastic Diffusion Simulator 
 
This applies a specific case from the wet lab notes: staining PETG fabric sheets of ~0.5mm diameter (which, important to note, isn't a flat sheet --> the model now uses Crank's cylinder solution instead of a plane-sheet one just for the current testing case), where the team's plan was to use a copper-carrying compounds (phthalate and sulfate as of now) 
 
Some complications found: 
 
1. **PETG isn't in the published polymer constant tables** 
2. **Copper phthalate contains a metal** and the whole original code (RDKit's logP, the Piringer equation) was built and validated for organic molecules only. This also means that inorganic molecules will be approximated using Crippen's method since they are out of the scope of the model 
 
However, these issues have been regulated ! 
#%% md 
## Equations used 
 
1. **Hydrophobicity - Crippen's logP method** (RDKit). Used in `get_desc()` to compute `logP`. 
Link: https://www.rdkit.org/docs/source/rdkit.Chem.Crippen.html 
 
2. **Piringer diffusion coefficient** : estimates how fast a molecule moves through a given polymer: 
 
$$D_P = 10^4 \cdot \exp\left[A_P' - 0.1351\,M_r^{2/3} + 0.003\,M_r - \frac{10454+\tau}{T}\right] \quad \text{(cm}^2\text{/s)}$$ 
 
$M_r$ = molecular weight, $T$ = temperature (K), $A_P'$ and $\tau$ = polymer-specific constants. Used in `piringer_diffusion_coefficient()`. 
 
Links: 
https://www.stevenabbott.co.uk/practical-solubility/diff-d-values.php 
https://www.sciencedirect.com/science/article/abs/pii/S0142941811001607 
chrome-extension://efaidnbmnnnibpcajpcglclefindmkaj/https://plasticseurope.org/wp-content/uploads/2021/11/20130719applicability_of_mathematical_modelling_for_the_estimation_of_specific_migration_of_substances.pdf 
 
3. **Crank's plane-sheet uptake** : fraction of saturation reached over time, for a flat sheet of thickness $L$ exposed on both faces. Defined below (`fractional_uptake` / `time_to_fraction`) but not actually used for the PETG case, since PETG here is a fiber, not a sheet but still kept for reference / other cases: 
 
$$\frac{M_t}{M_\infty} = 1 - \sum_{n=0}^{\infty} \frac{8}{(2n+1)^2\pi^2}\, \exp\!\left(-D(2n+1)^2\pi^2 t / L^2\right)$$ 
Links: 
https://www.sciencedirect.com/science/article/pii/S2590123025028622 
I took some inspo from here for the scipy part: https://www.mdpi.com/2076-3417/15/22/11857 
 
4. **Crank's cylinder uptake** :  the version actually used for the PETG fiber. Same idea as #3, but for radial diffusion into a cylinder of radius $a$ instead of a flat sheet: 
 
$$\frac{M_t}{M_\infty} = 1 - \sum_{n=1}^{\infty} \frac{4}{\alpha_n^2}\, \exp\!\left(-D\alpha_n^2 t / a^2\right), \qquad \alpha_n = \text{positive zeros of the Bessel function } J_0$$ 
 
Used in `fractional_uptake_cylinder()`, and inverted (solved for time given a target fraction) via `time_to_fraction_cylinder()`. 
 
Link: https://pythonforundergradengineers.com/crank-and-rocker-motion-with-python-and-matplotlib.html 
 
5. **Crank's cylinder concentration profile** : like #4, but gives concentration at any radial position $r$ inside the fiber (not just the average across the whole cross-section), which is what makes the surface-vs-center visuals possible: 
 
$$\frac{C(r,t)}{C_s} = 1 - 2\sum_{n=1}^{\infty} \frac{J_0(\alpha_n r/a)}{\alpha_n J_1(\alpha_n)}\, \exp\!\left(-D\alpha_n^2 t / a^2\right)$$ 
 
Used in `concentration_profile_cylinder()`. 
 
**Root-finding note:** `brentq` (Brent's method from `scipy.optimize`) searches for the time at which the uptake fraction hits a given target instead. 
Link: https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.brentq.html

## Descriptor extraction and parameter defining 
 
`get_desc()` turns a molecule's SMILES string into three properties: hydrophobicity (logP), aromatic ring content, and molecular weight.  
`POLYMER_PARAMS` uses a list of polymer constants found online used in the Piringer equation.  
#%% 
from rdkit import Chem
from rdkit.Chem import Crippen, Descriptors, rdMolDescriptors
import numpy as np
from scipy.optimize import brentq


def get_desc(smiles: str) -> dict:
    mol = Chem.MolFromSmiles(smiles)
    if mol is None:
        raise ValueError(f"Could not identify: {smiles!r}")
    return {
        "smiles": smiles,
        "logP": round(Crippen.MolLogP(mol), 3),
        "aromatic_atom_fraction": round(rdMolDescriptors.CalcNumAromaticRings(mol) and sum(1 for atom in mol.GetAtoms() if atom.GetIsAromatic()) / mol.GetNumAtoms(),3,),
        "molecular_weight": round(Descriptors.MolWt(mol), 2),
    }

POLYMER_PARAMS = {
    "LDPE":         {"Ap": 11.5, "tau": 0,    "Mr_range": (30, 2000),   "T_max_C": 80},
    "HDPE":         {"Ap": 14.5, "tau": 1577, "Mr_range": (30, 2000),   "T_max_C": 90},
    "PP":           {"Ap": 13.1, "tau": 1577, "Mr_range": (30, 2000),   "T_max_C": 120},
    "PS":           {"Ap": -1.0, "tau": 0,    "Mr_range": (104, 647),   "T_max_C": 70},
    "PET_above_Tg": {"Ap": 6.4,  "tau": 1577, "Mr_range": (32, 10000),  "T_max_C": 175},
    "PET_below_Tg": {"Ap": 3.1,  "tau": 1577, "Mr_range": (32, 10000),  "T_max_C": 70},
    "PVC_rigid":    {"Ap": -1.0, "tau": 0,    "Mr_range": (225, 10000), "T_max_C": 70},
    "PETG_approx":  {"Ap": 6.4,  "tau": 1577, "Mr_range": (32, 10000),  "T_max_C": 175},
}


def piringer_diffusion_coefficient(Mr, T_celsius, polymer):
    if polymer not in POLYMER_PARAMS:
        raise ValueError(f"never heard of {polymer!r}, pick one of {list(POLYMER_PARAMS)}")
    params = POLYMER_PARAMS[polymer]
    Ap, tau = params["Ap"], params["tau"]
    Mr_lo, Mr_hi = params["Mr_range"]
    if not (Mr_lo <= Mr <= Mr_hi):
        print(f"  [WARNING] Mr={Mr} is outside the validated range {params['Mr_range']} for {polymer}")
    if T_celsius > params["T_max_C"]:
        print(f"  [WARNING] T={T_celsius}C exceeds the validated max {params['T_max_C']}C for {polymer}")
    T_kelvin = T_celsius + 273.15
    exponent = Ap - 0.1351 * Mr ** (2 / 3) + 0.003 * Mr - (10454 + tau) / T_kelvin
    return 1e4 * np.exp(exponent)

def fractional_uptake(t, D, L, n_terms=50):
    t = np.asarray(t, dtype=float)
    total = np.zeros_like(t)
    for n in range(n_terms):
        coeff = 8.0 / ((2 * n + 1) ** 2 * np.pi ** 2)
        total += coeff * np.exp(-D * (2 * n + 1) ** 2 * np.pi ** 2 * t / L ** 2)
    return 1.0 - total


def time_to_fraction(target_fraction, D, L):

    if not (0 < target_fraction < 1):
        raise ValueError(f"target_fraction needs to be between 0 and 1, got {target_fraction}")
    if D <= 0:
        raise ValueError(f"D needs to be positive, got {D}")
    def f(t):
        return fractional_uptake(t, D, L) - target_fraction
    t_hi = L ** 2 / D
    while f(t_hi) < 0:
        t_hi *= 2
    return brentq(f, 1e-12, t_hi)

from scipy.special import jn_zeros


def fractional_uptake_cylinder(t, D, a, n_terms=50):
    alphas = jn_zeros(0, n_terms)
    t = np.asarray(t, dtype=float)
    total = np.zeros_like(t)
    for alpha in alphas:
        total += (4.0 / alpha ** 2) * np.exp(-D * alpha ** 2 * t / a ** 2)
    return 1.0 - total


def time_to_fraction_cylinder(target_fraction, D, a):

    if not (0 < target_fraction < 1):
        raise ValueError(f"target_fraction needs to be between 0 and 1, got {target_fraction}")
    if D <= 0:
        raise ValueError(f"D needs to be positive, got {D}")
    def f(t):
        return fractional_uptake_cylinder(t, D, a) - target_fraction
    t_hi = a ** 2 / D
    while f(t_hi) < 0:
        t_hi *= 2
    return brentq(f, 1e-12, t_hi)

## Organic proxy 
 
Since the organic part of copper phthalate is what affects the polymer's diffusion, a reasonable alternative is diethyl phthalate since it can be handled by RDKit and Piringer. It won't capture whatever effect the copper has, but it gives an estimate for how fast a phthalate-ish molecule moves through PETG. 
 
The PETG is a fabric with ~0.5 mm diameter fibers (radius = 0.25 mm = 0.025 cm), roughly 90 C. Since this is a fiber, not a flat sheet, the calculation below uses the cylinder diffusion solution with a fixed fiber radius instead of scanning through plausible sheet thicknesses. 
#%% 
smiles = "CCOC(=O)c1ccccc1C(=O)OCC"
polymer = "PETG_approx"
T_celsius = 90
fiber_radius_cm = 0.025
d = get_desc(smiles)
print("Descriptors:", d)

D = piringer_diffusion_coefficient(d["molecular_weight"], T_celsius, polymer)
print(f"\nD at {T_celsius} C in {polymer}: {D:.3e} cm^2/s\n")

print(f"Predicted uptake into a {fiber_radius_cm*2*10:.2f} mm diameter fiber:")
for frac in [0.10, 0.50, 0.95]:
    t = time_to_fraction_cylinder(frac, D, fiber_radius_cm)
    print(f"  {int(frac*100):3d}% uptake at {t/60:8.1f} min  ({t/3600:6.2f} h)")

## Concentration profile inside the fiber: Copper Phthalate 
#%% 
from scipy.special import j0, j1

def concentration_cylinder(r, t, D, a, Cs=1.0, n_terms=2000):
    alphas = jn_zeros(0, n_terms)
    r = np.asarray(r, dtype=float)
    total = np.zeros_like(r)
    for alpha in alphas:
        total += (j0(alpha * r / a) / (alpha * j1(alpha))) * np.exp(-D * alpha ** 2 * t / a ** 2)
    return Cs * (1.0 - 2.0 * total)
#%% 
import matplotlib.pyplot as plt

times_min = [10, 30, 63, 120, 300, 600]

fig, ax = plt.subplots(1, 1, figsize=(7, 5))

r_range = np.linspace(0, fiber_radius_cm, 300)
for t_min in times_min:
    c = concentration_cylinder(r_range, t_min * 60, D, fiber_radius_cm)
    ax.plot(r_range / fiber_radius_cm, c, label=f"{t_min} min")
ax.set_xlabel("radial position (r / fiber radius)  -  0 = center, 1 = surface")
ax.set_ylabel("relative concentration C/C_s")
ax.set_title("Concentration profile: center vs. surface, over time")
ax.legend(title="time", fontsize=8)

# Shows fiber cross-section as a disc colored by local concentration
theta = np.linspace(0, 2 * np.pi, 200)
rr = np.linspace(0, fiber_radius_cm, 150)
R, THETA = np.meshgrid(rr, theta)
X, Y = R * np.cos(THETA), R * np.sin(THETA)

snap_subset = [10, 63, 300, 600]
fig2, axes2 = plt.subplots(1, len(snap_subset), figsize=(4 * len(snap_subset), 4.2))
for ax, t_min in zip(axes2, snap_subset):
    C = concentration_cylinder(R, t_min * 60, D, fiber_radius_cm)
    pcm = ax.pcolormesh(X * 10, Y * 10, C, cmap="viridis", vmin=0, vmax=1, shading="auto")
    ax.set_aspect("equal")
    ax.set_title(f"t = {t_min} min")
    ax.set_xlabel("mm")
fig2.colorbar(pcm, ax=axes2, label="relative concentration C/C_s")
fig2.suptitle("PETG fiber cross-section: diethyl phthalate concentration (surface --> center)", y=1)

fig.tight_layout()
plt.show()

## Copper sulfate vs. copper phthalate 
#%% 
salts = {
    "copper sulfate": "[Cu+2].[O-]S(=O)(=O)[O-]",
    "copper phthalate": "[Cu+2].[O-]C(=O)c1ccccc1C(=O)[O-]",
}

results = {}
for name, smi in salts.items():
    d = get_desc(smi)
    D = piringer_diffusion_coefficient(d["molecular_weight"], T_celsius, polymer)
    results[name] = (d, D)

    print(f"--- {name} ---")
    print(f"  descriptors: {d}")
    print(f"  D = {D:.3e} cm^2/s")
    for frac in [0.10, 0.50, 0.95]:
        t = time_to_fraction_cylinder(frac, D, fiber_radius_cm)
        print(f"  {int(frac*100):3d}% uptake at {t/60:8.1f} min  ({t/3600:6.2f} h)")
    print()

ratio = results["copper phthalate"][1] / results["copper sulfate"][1]
print(f"D(copper phthalate) / D(copper sulfate) = {ratio:.2f}  "
      f"--> phthalate predicted to diffuse ~{1/ratio:.1f}x slower than sulfate")
